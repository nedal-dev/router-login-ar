# router-login-ar

أداة صغيرة مفتوحة المصدر تكتشف عنوان البوابة الافتراضية للشبكة وتفتح صفحة إعدادات الراوتر في المتصفح. تعمل محليًا ولا تجمع كلمات المرور أو بيانات الشبكة ولا ترسلها إلى أي خادم.

## التنزيل السريع

| نظام التشغيل | الملف المباشر |
|---|---|
| Windows 10 وWindows 11 | [تنزيل router-login.bat](https://github.com/nedal-dev/router-login-ar/raw/refs/heads/main/router-login.bat) |
| Linux وmacOS | [تنزيل router-login.sh](https://github.com/nedal-dev/router-login-ar/raw/refs/heads/main/router-login.sh) |

## الاستخدام على Windows

1. نزّل ملف `router-login.bat`.
2. تأكد من اتصال الكمبيوتر بشبكة الراوتر عبر Wi-Fi أو كابل الشبكة.
3. انقر مرتين على الملف.
4. يكتشف السكربت عنوان الراوتر ويفتحه في المتصفح الافتراضي.

يعتمد الاكتشاف على بيانات التوجيه في النظام، وليس على عبارة `Default Gateway` المترجمة، لذلك لا تتأثر الأداة بلغة Windows.

## الاستخدام على Linux وmacOS

بعد تنزيل `router-login.sh`، افتح الطرفية داخل مجلد التنزيل ونفّذ:

```bash
chmod +x router-login.sh
./router-login.sh
```

يستخدم السكربت الأمر المناسب للنظام:

- `Get-NetRoute` مع طريقة احتياطية على Windows.
- `ip route` مع طرق احتياطية على Linux.
- `route -n get default` على macOS.

## إدخال عنوان يدوي

إذا لم يتمكن السكربت من اكتشاف العنوان، يمكنك تمرير عنوان IP أو رابط كامل:

```text
router-login.bat 192.168.1.1
router-login.bat https://192.168.1.1
```

```bash
./router-login.sh 192.168.1.1
./router-login.sh https://192.168.1.1
```

## إذا لم تفتح الصفحة

- تأكد من اتصال الجهاز بشبكة الراوتر نفسها، وليس ببيانات الهاتف أو شبكة أخرى.
- جرّب فتح العنوان الذي يعرضه السكربت يدويًا في المتصفح.
- إذا ظهر تحذير شهادة، فقد يكون الراوتر يستخدم شهادة محلية غير موثوقة.
- بعض أجهزة الراوتر لا تسمح بالدخول من شبكة الضيوف.
- لا تضغط زر Reset لمجرد أن الصفحة لم تفتح؛ هذا الزر قد يمسح إعدادات الاتصال.

## الخصوصية والحدود

- تعمل الأداة محليًا بالكامل.
- لا تقرأ اسم المستخدم أو كلمة مرور الراوتر.
- لا تغيّر أي إعداد داخل الراوتر.
- وظيفتها الوحيدة اكتشاف بوابة الشبكة وفتح عنوانها.
- قد تحتاج بعض الشبكات المؤسسية أو شبكات VPN إلى إدخال العنوان يدويًا.

## الإبلاغ عن مشكلة

افتح Issue واذكر نظام التشغيل وطريقة الاتصال والرسالة التي ظهرت. لا تنشر كلمة مرور الراوتر أو عنوان IP العام أو أي بيانات شخصية.

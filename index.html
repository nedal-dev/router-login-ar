افتح صفحة إعدادات الراوتر تلقائيًا

نزّل الملف المناسب لنظامك وشغّله. ستكتشف الأداة عنوان بوابة الشبكة وتفتح صفحة الراوتر في المتصفح من دون البحث عن عنوان IP يدويًا.

اختر نظام التشغيل

إذا كنت تستخدم Windows اختر الزر الأول. مستخدمو Linux وmacOS يختارون الزر الثاني.

تنزيل ملف Windows تنزيل ملف Linux / macOS

عرض الكود المصدري على GitHub

التشغيل على Windows

  1. نزّل ملف router-login.bat.
  2. تأكد من اتصال الكمبيوتر بشبكة الراوتر.
  3. انقر مرتين على الملف.
  4. ستفتح صفحة الراوتر في المتصفح الافتراضي.

لا يعتمد الاكتشاف على لغة Windows، لذلك يعمل حتى لو كانت واجهة النظام هولندية أو عربية.

التشغيل على Linux أو macOS

  1. نزّل ملف router-login.sh.
  2. امنحه صلاحية التشغيل بالأمر chmod +x router-login.sh.
  3. شغّله بالأمر ./router-login.sh.

إذا تعذر الاكتشاف، يمكنك كتابة العنوان يدويًا بعد اسم الملف، مثل ./router-login.sh 192.168.1.1.

إذا لم تفتح صفحة الراوتر

  1. تأكد من اتصال الجهاز بشبكة الراوتر نفسها.
  2. جرّب العنوان الذي تعرضه الأداة يدويًا.
  3. لا تستخدم زر Reset لمجرد أن الصفحة لم تفتح؛ قد يمسح إعدادات الاتصال.
  4. قد تمنع شبكة الضيوف الوصول إلى صفحة الإدارة.

الخصوصية والأمان

تعمل الأداة محليًا بالكامل. لا تجمع بيانات، ولا تقرأ كلمات المرور، ولا تغيّر إعدادات الراوتر؛ وظيفتها فقط اكتشاف عنوان بوابة الشبكة وفتحه.

تحتاج شرحًا أوسع؟

يتضمن مقال إدراك طرق معرفة عنوان الراوتر من الهاتف والكمبيوتر وحلول مشكلة عدم فتح صفحة الإعدادات.
